Instructions

  1. Pick your language with the select menu at the top right (English, Italiano, Español, Français).
  2. Click the big box at the top (or drop your save file on the page).
    Save files are located at: "C:\Program Files (x86)\Steam\steamapps\common\Legends of the Dark\Legends of the Dark_Data\SavedGames" inside folders 1, 2, 3, ... and have the extension .sav.
    The save loads straight away.
  3. Use the tabs to move between Common, each hero, the Shop, the Shop items, the Enemies and the Missions.
  4. WARNING: the Missions tab can cause unknown progression problems. It is meant for replaying missions after an act is complete, is experimental and has had only light testing in the game (Act 2 none), so use it on a copy of your save. Tick which missions are done and which are open on the map, then press Apply mission changes before getting the new save file. Act 2 is less certain than Act 1.
  5. Below the missions, the Events section does the same for narrative and city events (even less certain).
  6. The New Game+ button (top bar) starts the story again from Quest 1 and keeps your items, recipes, weapons, materials, gold, skills, feats, enemy weaknesses and equipped gear. In the game, start a new Act 1 campaign with the heroes you want to play and set the difficulty; as soon as you can save, save and exit. Then choose that save in the New Game+ window, pick your options (one tick box resets the virtues of all heroes), build it, and replace the new campaign's save with the downloaded file by copying it into that slot's folder. The save you have open is not changed. It is experimental and has had only light testing in the game.
  7. Tick or untick a box to add or remove something. Items you can craft have a Recipe, a Base, a Plus recipe and an Upgraded box. The buttons at the top ("I want it all", "All skills", "All feats", "Reveal enemies", "Reset to default", "Clean up duplicates") do a lot at once.
  8. An Act 1 campaign starts with the Act 2 content hidden. Untick Hide all Act 2 content to see it (that box only appears on Act 1 campaigns; an Act 2 save never hides anything). It stays locked unless the save owns Act 2 or you tick Act 2 content allowed.
  9. Click the green Get the new save file button to download the modified file.
  10. Copy the new file into the folder "C:\Program Files (x86)\Steam\steamapps\common\Legends of the Dark\Legends of the Dark_Data\SavedGames" (choose folder 1, 2, 3, ... based on the campaign you want to update).
  11. The new file is named one second after the one you loaded, so the game treats it as the most recent. If you loaded a file with a different name, rename the new file so it appears as the latest: for example, if the latest save is 2025-01-01_12-00-00, use 2025-01-01_12-00-01.

NOTE: If you mark an ongoing feat as completed, the app will not allow you to claim the rewards for that feat and, as a result, it will make it impossible to take on new feats.

Back up your saves first, and try edits on a copy.

Istruzioni

  1. Puoi cambiare la lingua utilizzando il select in alto a destra (English, Italiano, Español, Français).
  2. Fai clic sul grande riquadro in alto (oppure trascina il file di salvataggio sulla pagina).
    I file di salvataggio si trovano in: "C:\Programmi (x86)\Steam\steamapps\common\Legends of the Dark\Legends of the Dark_Data\SavedGames" nelle cartelle 1, 2, 3, ... e hanno estensione .sav.
    Il salvataggio viene caricato subito.
  3. Usa le schede per passare tra Comuni, ogni eroe, il Negozio, gli Articoli negozio, i Nemici e le Missioni.
  4. ATTENZIONE: la scheda Missioni può causare problemi di progressione sconosciuti. È pensata per rigiocare missioni dopo che un atto è completo, è sperimentale e nel gioco è stata provata solo poco (l'Atto 2 per niente): usala su una copia del salvataggio. Spunta quali missioni sono completate e quali sono aperte sulla mappa, poi premi Apply mission changes prima di scaricare il nuovo salvataggio (il testo della scheda è solo in inglese). L'Atto 2 è meno sicuro dell'Atto 1.
  5. Sotto le missioni, la sezione Events fa lo stesso per gli eventi narrativi e cittadini (ancora meno sicuro).
  6. Il pulsante New Game+ (barra in alto) ricomincia la storia dalla Missione 1 e conserva oggetti, ricette, armi, materiali, oro, abilità, imprese, debolezze dei nemici ed equipaggiamento. Nel gioco, avvia una nuova campagna dell'Atto 1 con gli eroi che vuoi giocare e imposta la difficoltà; appena puoi salvare, salva ed esci. Poi scegli quel salvataggio nella finestra New Game+, scegli le opzioni (una casella resetta le virtù di tutti gli eroi), crea il risultato e sostituisci il salvataggio della nuova campagna con il file scaricato, copiandolo nella cartella di quello slot. Il salvataggio aperto non cambia. È sperimentale e provato solo poco nel gioco (il testo è solo in inglese).
  7. Spunta o deseleziona una casella per aggiungere o rimuovere qualcosa. Gli oggetti fabbricabili hanno le caselle Recipe, Base, Plus recipe e Upgraded. I pulsanti in alto ("I want it all", "All skills", "All feats", "Reveal enemies", "Reset to default", "Clean up duplicates") fanno molte cose in una volta.
  8. Una campagna dell'Atto 1 inizia con i contenuti dell'Atto 2 nascosti. Deseleziona Hide all Act 2 content per vederli (la casella compare solo nelle campagne dell'Atto 1; un salvataggio dell'Atto 2 non nasconde nulla). Restano bloccati a meno che il salvataggio non possieda l'Atto 2 o tu non selezioni Act 2 content allowed.
  9. Fai clic sul pulsante verde Get the new save file per scaricare il file modificato.
  10. Copia il nuovo file nella cartella "C:\Programmi (x86)\Steam\steamapps\common\Legends of the Dark\Legends of the Dark_Data\SavedGames" (scegli la cartella 1, 2, 3, ... in base alla campagna).
  11. Il nuovo file ha un nome con un secondo in più rispetto a quello caricato, così il gioco lo considera il più recente. Se hai caricato un file con un nome diverso, rinomina il nuovo file in modo che risulti l'ultimo: ad esempio, se l'ultimo salvataggio è 2025-01-01_12-00-00, usa 2025-01-01_12-00-01.

NOTA: Se segni come completata un'impresa in corso, l'app non ti permetterà di riscuotere le ricompense di quell'impresa e, di conseguenza, sarà impossibile intraprendere nuove imprese.

Fai prima una copia di sicurezza dei salvataggi e prova le modifiche su una copia.

Instrucciones

  1. Elige el idioma con el menú select de arriba a la derecha (English, Italiano, Español, Français).
  2. Haz clic en el recuadro grande de arriba (o suelta tu archivo de guardado sobre la página).
    Los archivos de guardado están en: "C:\Program Files (x86)\Steam\steamapps\common\Legends of the Dark\Legends of the Dark_Data\SavedGames" dentro de las carpetas 1, 2, 3, ... y tienen la extensión .sav.
    El guardado se carga enseguida.
  3. Usa las pestañas para moverte entre Común, cada héroe, la Tienda, los Artículos de la tienda, los Enemigos y las Misiones.
  4. ADVERTENCIA: la pestaña Misiones puede causar problemas de progresión desconocidos. Está pensada para volver a jugar misiones cuando un acto ya está completo, es experimental y solo se ha probado un poco en el juego (el Acto 2 nada), así que úsala en una copia de tu guardado. Marca qué misiones están hechas y cuáles están abiertas en el mapa, y pulsa Aplicar cambios de misiones antes de obtener el nuevo guardado. El Acto 2 es menos fiable que el Acto 1.
  5. Debajo de las misiones, la sección Eventos hace lo mismo con los eventos narrativos y de ciudad (todavía menos fiable).
  6. El botón Nueva partida+ (barra superior) empieza la historia otra vez desde la Misión 1 y conserva objetos, recetas, armas, materiales, oro, habilidades, gestas, debilidades de enemigos y equipo. En el juego, empieza una campaña nueva del Acto 1 con los héroes que quieras jugar y ajusta la dificultad; en cuanto puedas guardar, guarda y sal. Luego elige ese guardado en la ventana de Nueva partida+, elige tus opciones (una casilla restablece las virtudes de todos los héroes), créalo y sustituye el guardado de la campaña nueva por el archivo descargado, copiándolo en la carpeta de esa ranura. El guardado que tienes abierto no cambia. Es experimental y solo se ha probado un poco en el juego.
  7. Marca o desmarca una casilla para añadir o quitar algo. Lo que se puede fabricar tiene las casillas Receta, Base, Receta mejorada y Mejorado. Los botones de arriba ("¡Lo quiero todo!", "Todas las habilidades", "Todas las hazañas", "Revelar enemigos", "Restablecer valores iniciales", "Limpiar duplicados") hacen muchas cosas a la vez.
  8. Una campaña del Acto 1 empieza con el contenido del Acto 2 oculto. Desmarca Ocultar todo el contenido del Acto 2 para verlo (esa casilla solo aparece en campañas del Acto 1; un guardado del Acto 2 nunca oculta nada). Sigue bloqueado salvo que el guardado tenga el Acto 2 o marques Contenido del Acto 2 permitido.
  9. Haz clic en el botón verde Obtener el nuevo archivo de guardado para descargar el archivo modificado.
  10. Copia el nuevo archivo en la carpeta "C:\Program Files (x86)\Steam\steamapps\common\Legends of the Dark\Legends of the Dark_Data\SavedGames" (elige la carpeta 1, 2, 3, ... según la campaña que quieras actualizar).
  11. El archivo nuevo se nombra un segundo después del que cargaste, así que el juego lo toma como el más reciente. Si cargaste un archivo con otro nombre, renombra el nuevo para que aparezca como el último: por ejemplo, si el último guardado es 2025-01-01_12-00-00, usa 2025-01-01_12-00-01.

NOTA: Si marcas como completada una hazaña en curso, la aplicación no te dejará reclamar sus recompensas y, como consecuencia, será imposible emprender hazañas nuevas.

Haz primero una copia de seguridad de tus guardados y prueba los cambios en una copia.

Mode d'emploi

  1. Choisissez votre langue avec le menu select en haut à droite (English, Italiano, Español, Français).
  2. Cliquez sur la grande zone en haut (ou déposez votre fichier de sauvegarde sur la page).
    Les fichiers de sauvegarde se trouvent dans : "C:\Program Files (x86)\Steam\steamapps\common\Legends of the Dark\Legends of the Dark_Data\SavedGames" dans les dossiers 1, 2, 3, ... et ont l'extension .sav.
    La sauvegarde se charge immédiatement.
  3. Utilisez les onglets pour passer de Commun à chaque héros, à la Boutique, aux Articles de la boutique, aux Ennemis et aux Missions.
  4. AVERTISSEMENT : l'onglet Missions peut causer des problèmes de progression inconnus. Il est prévu pour rejouer des missions une fois un acte terminé, est expérimental et n'a été que peu testé dans le jeu (l'Acte 2 pas du tout) : utilisez-le sur une copie de votre sauvegarde. Cochez les missions terminées et celles ouvertes sur la carte, puis appuyez sur Appliquer les changements de missions avant de récupérer la nouvelle sauvegarde. L'Acte 2 est moins sûr que l'Acte 1.
  5. Sous les missions, la section Événements fait la même chose pour les événements narratifs et de ville (encore moins sûr).
  6. Le bouton Nouvelle partie+ (barre du haut) recommence l'histoire à la Mission 1 et garde objets, recettes, armes, matériaux, or, compétences, exploits, faiblesses des ennemis et équipement. Dans le jeu, lancez une nouvelle campagne de l'Acte 1 avec les héros que vous voulez jouer et réglez la difficulté ; dès que vous pouvez sauvegarder, sauvegardez et quittez. Choisissez ensuite cette sauvegarde dans la fenêtre Nouvelle partie+, choisissez vos options (une case remet à zéro les vertus de tous les héros), créez le résultat et remplacez la sauvegarde de la nouvelle campagne par le fichier téléchargé, en le copiant dans le dossier de cet emplacement. La sauvegarde ouverte n'est pas modifiée. C'est expérimental et peu testé dans le jeu.
  7. Cochez ou décochez une case pour ajouter ou retirer quelque chose. Ce qui peut être fabriqué a les cases Recette, Base, Recette améliorée et Amélioré. Les boutons du haut (« Je veux tout ! », « Toutes les compétences », « Tous les exploits », « Révéler les ennemis », « Rétablir les valeurs initiales », « Nettoyer les doublons ») font beaucoup de choses d'un coup.
  8. Une campagne de l'Acte 1 commence avec le contenu de l'Acte 2 masqué. Décochez Masquer tout le contenu de l'Acte 2 pour le voir (cette case n'apparaît que pour les campagnes de l'Acte 1 ; une sauvegarde de l'Acte 2 ne masque rien). Il reste verrouillé sauf si la sauvegarde possède l'Acte 2 ou si vous cochez Contenu de l'Acte 2 autorisé.
  9. Cliquez sur le bouton vert Obtenir le nouveau fichier de sauvegarde pour télécharger le fichier modifié.
  10. Copiez le nouveau fichier dans le dossier "C:\Program Files (x86)\Steam\steamapps\common\Legends of the Dark\Legends of the Dark_Data\SavedGames" (choisissez le dossier 1, 2, 3, ... selon la campagne à mettre à jour).
  11. Le nouveau fichier porte un nom plus récent d'une seconde que celui que vous avez chargé, donc le jeu le considère comme le plus récent. Si vous avez chargé un fichier avec un autre nom, renommez le nouveau pour qu'il apparaisse comme le dernier : par exemple, si la dernière sauvegarde est 2025-01-01_12-00-00, utilisez 2025-01-01_12-00-01.

NOTE : si vous marquez comme accompli un exploit en cours, l'application ne vous laissera pas réclamer ses récompenses et il deviendra donc impossible d'entreprendre de nouveaux exploits.

Faites d'abord une copie de sauvegarde de vos sauvegardes et testez les modifications sur une copie.
