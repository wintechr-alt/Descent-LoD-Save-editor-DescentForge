Instructions

  1. Pick your language with the select menu at the top right (English, Italiano, Español, Français).
  2. Click the big box at the top (or drop your save file on the page).
    Save files are located at: "C:\Program Files (x86)\Steam\steamapps\common\Legends of the Dark\Legends of the Dark_Data\SavedGames" inside folders 1, 2, 3, ... and have the extension .sav.
    The save loads straight away.
  3. Use the tabs to move between Common, each hero, the Shop, the Shop items and the Enemies.
  4. Tick or untick a box to add or remove something. Items you can craft have a Recipe, a Base, a Plus recipe and an Upgraded box. The buttons at the top ("I want it all", "All skills", "All feats", "Reveal enemies", "Reset to default", "Clean up duplicates") do a lot at once.
  5. An Act 1 campaign starts with the Act 2 content hidden. Untick Hide all Act 2 content to see it. It stays locked unless the save owns Act 2 or you tick Act 2 content allowed.
  6. Click the green Get the new save file button to download the modified file.
  7. Copy the new file into the folder "C:\Program Files (x86)\Steam\steamapps\common\Legends of the Dark\Legends of the Dark_Data\SavedGames" (choose folder 1, 2, 3, ... based on the campaign you want to update).
  8. The new file is named one second after the one you loaded, so the game treats it as the most recent. If you loaded a file with a different name, rename the new file so it appears as the latest: for example, if the latest save is 2025-01-01_12-00-00, use 2025-01-01_12-00-01.

NOTE: If you mark an ongoing feat as completed, the app will not allow you to claim the rewards for that feat and, as a result, it will make it impossible to take on new feats.

Back up your saves first, and try edits on a copy.

Istruzioni

  1. Puoi cambiare la lingua utilizzando il select in alto a destra (English, Italiano, Español, Français).
  2. Fai clic sul grande riquadro in alto (oppure trascina il file di salvataggio sulla pagina).
    I file di salvataggio si trovano in: "C:\Programmi (x86)\Steam\steamapps\common\Legends of the Dark\Legends of the Dark_Data\SavedGames" nelle cartelle 1, 2, 3, ... e hanno estensione .sav.
    Il salvataggio viene caricato subito.
  3. Usa le schede per passare tra Comuni, ogni eroe, il Negozio, gli Articoli negozio e i Nemici.
  4. Spunta o deseleziona una casella per aggiungere o rimuovere qualcosa. Gli oggetti fabbricabili hanno le caselle Recipe, Base, Plus recipe e Upgraded. I pulsanti in alto ("I want it all", "All skills", "All feats", "Reveal enemies", "Reset to default", "Clean up duplicates") fanno molte cose in una volta.
  5. Una campagna dell'Atto 1 inizia con i contenuti dell'Atto 2 nascosti. Deseleziona Hide all Act 2 content per vederli. Restano bloccati a meno che il salvataggio non possieda l'Atto 2 o tu non selezioni Act 2 content allowed.
  6. Fai clic sul pulsante verde Get the new save file per scaricare il file modificato.
  7. Copia il nuovo file nella cartella "C:\Programmi (x86)\Steam\steamapps\common\Legends of the Dark\Legends of the Dark_Data\SavedGames" (scegli la cartella 1, 2, 3, ... in base alla campagna).
  8. Il nuovo file ha un nome con un secondo in più rispetto a quello caricato, così il gioco lo considera il più recente. Se hai caricato un file con un nome diverso, rinomina il nuovo file in modo che risulti l'ultimo: ad esempio, se l'ultimo salvataggio è 2025-01-01_12-00-00, usa 2025-01-01_12-00-01.

NOTA: Se segni come completata un'impresa in corso, l'app non ti permetterà di riscuotere le ricompense di quell'impresa e, di conseguenza, sarà impossibile intraprendere nuove imprese.

Fai prima una copia di sicurezza dei salvataggi e prova le modifiche su una copia.

Instrucciones

  1. Elige el idioma con el menú select de arriba a la derecha (English, Italiano, Español, Français).
  2. Haz clic en el recuadro grande de arriba (o suelta tu archivo de guardado sobre la página).
    Los archivos de guardado están en: "C:\Program Files (x86)\Steam\steamapps\common\Legends of the Dark\Legends of the Dark_Data\SavedGames" dentro de las carpetas 1, 2, 3, ... y tienen la extensión .sav.
    El guardado se carga enseguida.
  3. Usa las pestañas para moverte entre Común, cada héroe, la Tienda, los Artículos de la tienda y los Enemigos.
  4. Marca o desmarca una casilla para añadir o quitar algo. Lo que se puede fabricar tiene las casillas Receta, Base, Receta mejorada y Mejorado. Los botones de arriba ("¡Lo quiero todo!", "Todas las habilidades", "Todas las hazañas", "Revelar enemigos", "Restablecer valores iniciales", "Limpiar duplicados") hacen muchas cosas a la vez.
  5. Una campaña del Acto 1 empieza con el contenido del Acto 2 oculto. Desmarca Ocultar todo el contenido del Acto 2 para verlo. Sigue bloqueado salvo que el guardado tenga el Acto 2 o marques Contenido del Acto 2 permitido.
  6. Haz clic en el botón verde Obtener el nuevo archivo de guardado para descargar el archivo modificado.
  7. Copia el nuevo archivo en la carpeta "C:\Program Files (x86)\Steam\steamapps\common\Legends of the Dark\Legends of the Dark_Data\SavedGames" (elige la carpeta 1, 2, 3, ... según la campaña que quieras actualizar).
  8. El archivo nuevo se nombra un segundo después del que cargaste, así que el juego lo toma como el más reciente. Si cargaste un archivo con otro nombre, renombra el nuevo para que aparezca como el último: por ejemplo, si el último guardado es 2025-01-01_12-00-00, usa 2025-01-01_12-00-01.

NOTA: Si marcas como completada una hazaña en curso, la aplicación no te dejará reclamar sus recompensas y, como consecuencia, será imposible emprender hazañas nuevas.

Haz primero una copia de seguridad de tus guardados y prueba los cambios en una copia.

Mode d'emploi

  1. Choisissez votre langue avec le menu select en haut à droite (English, Italiano, Español, Français).
  2. Cliquez sur la grande zone en haut (ou déposez votre fichier de sauvegarde sur la page).
    Les fichiers de sauvegarde se trouvent dans : "C:\Program Files (x86)\Steam\steamapps\common\Legends of the Dark\Legends of the Dark_Data\SavedGames" dans les dossiers 1, 2, 3, ... et ont l'extension .sav.
    La sauvegarde se charge immédiatement.
  3. Utilisez les onglets pour passer de Commun à chaque héros, à la Boutique, aux Articles de la boutique et aux Ennemis.
  4. Cochez ou décochez une case pour ajouter ou retirer quelque chose. Ce qui peut être fabriqué a les cases Recette, Base, Recette améliorée et Amélioré. Les boutons du haut (« Je veux tout ! », « Toutes les compétences », « Tous les exploits », « Révéler les ennemis », « Rétablir les valeurs initiales », « Nettoyer les doublons ») font beaucoup de choses d'un coup.
  5. Une campagne de l'Acte 1 commence avec le contenu de l'Acte 2 masqué. Décochez Masquer tout le contenu de l'Acte 2 pour le voir. Il reste verrouillé sauf si la sauvegarde possède l'Acte 2 ou si vous cochez Contenu de l'Acte 2 autorisé.
  6. Cliquez sur le bouton vert Obtenir le nouveau fichier de sauvegarde pour télécharger le fichier modifié.
  7. Copiez le nouveau fichier dans le dossier "C:\Program Files (x86)\Steam\steamapps\common\Legends of the Dark\Legends of the Dark_Data\SavedGames" (choisissez le dossier 1, 2, 3, ... selon la campagne à mettre à jour).
  8. Le nouveau fichier porte un nom plus récent d'une seconde que celui que vous avez chargé, donc le jeu le considère comme le plus récent. Si vous avez chargé un fichier avec un autre nom, renommez le nouveau pour qu'il apparaisse comme le dernier : par exemple, si la dernière sauvegarde est 2025-01-01_12-00-00, utilisez 2025-01-01_12-00-01.

NOTE : si vous marquez comme accompli un exploit en cours, l'application ne vous laissera pas réclamer ses récompenses et il deviendra donc impossible d'entreprendre de nouveaux exploits.

Faites d'abord une copie de sauvegarde de vos sauvegardes et testez les modifications sur une copie.
