    ITEM OR RECIPE FOR SALE

    Items & recipes for sale

    Each is sold once. Items you own and recipes you know can't be added, so buying can't make a duplicate.

    Only what you can still add is listed: items you own and recipes you know are left out. Weapons are grouped by hero, with each weapon's part A, part B and part C like the hero pages.

    "Add everything" puts every item and recipe listed below on sale (Act 2 ones only when the campaign allows them). That can be a few hundred entries, which hasn't been tried in the game, so try it on a copy of your save first. "Clear all" takes them all off again.

    Enemy weaknesses

    Tick an enemy to reveal all its weaknesses and resistances, or untick it to forget it. Solid tags are revealed. Dashed tags are still hidden.

    • The small "flags" number under an enemy is what the save stores for it. One part of that number (bit 0) isn't understood and is ignored; it's set whenever an enemy is revealed.
    • The weaknesses and resistances come from DescentForge's enemy list. Enemies in a save that aren't on that list are never changed.

    WARNING: unknown progression issues

    Changing missions can cause progression problems that nobody has mapped yet. The game may unlock the wrong things, skip or repeat story, or stop the campaign from moving on.

    This tab is meant for replaying missions after an act is complete: untick Done on a finished mission and tick Open on the map to play it again. It is not a way to skip ahead, and it has not been tested for that.

    Back up your save first and try it on a copy.

    Missions Experimental

    Experimental. This was worked out from a few saves, so use it on a copy of your save. Act 1 comes from a before and after pair and has had only light testing in the game; Act 2 comes from one finished save and has not been tested in the game.

    This is an Act 2 campaign. Act 2 was worked out from one finished save, with no before and after pair, so it is less certain than Act 1. Act 2 results can't be edited, and its two mission counters are left as they are.

    • Tick Done for the missions the party has finished and pick Won or Lost. Tick Open on the map for the missions the map should offer next.
    • Press Apply mission changes. It updates the finished and open lists, the campaign log, each mission's result, the map's last mission and the campaign progression number (18 plus 2 for every mission done).
    • Heroes who haven't joined yet, gold, XP, feat rerolls and story events are left alone.

    MISSION DONE RESULT OPEN ON MAP

    Events Experimental

    Experimental, and less certain than missions: no save shows an event being played, only events waiting and events finished. A narrative event waits in the same open list as the missions. A city event waits in town; it can be marked done or taken off the town, but not put back, because where it stood is only known while it waits. Story choices that events make are not touched.

    EVENT KIND DONE PENDING

    New Game+ Experimental

    New Game+ starts the story again from Quest 1 and keeps what you have earned: items, recipes, weapons and upgrades, materials, gold, skills, feats, enemy weaknesses and each hero's equipped weapons and trinket. It does this by moving all of that into the save of a brand-new campaign. The save you have open is not changed.

    1. In the game, start a new Act 1 campaign with the heroes you want to play, and set the difficulty.
    2. As soon as you can save, save, then exit the game.
    3. Choose that new campaign's save below, pick your options and press Build New Game+.
    4. Download the result and replace the new campaign's save with it: copy it into that slot's folder. It is named one second newer, so the game loads it.

    Everything about the story comes from the new campaign: missions, quest results, story choices, events, the shop, party name, difficulty, XP, feat rerolls, Legends and companions. Which heroes play comes from the new campaign too, so it is not changed here.

    It has had only light testing in the game. Back up your saves first.
