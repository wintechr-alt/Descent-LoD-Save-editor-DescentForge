# Credits and acknowledgements

## Original editor

**Dano1307**, for [Descent-LoD-Save-editor](https://github.com/Dano1307/Descent-LoD-Save-editor)
(live at https://dano1307.github.io/Descent-LoD-Save-editor/). This fork is built on it. The page
design, the lists of item, skill and feat IDs, the pictures, and the code that reads and writes the
save came from the original editor. Thank you for making it and putting it online.

## DescentForge

**DescentForge**, the community campaign builder for *Descent: Legends of the Dark*. This fork
uses data from its built-in catalog:

- English and Spanish names for items, recipes, materials and enemies (`script/names.js`,
  `script/enemies.js`)
- the list of every recipe in the game, and the unusual spellings of a few recipe IDs
- each enemy's weaknesses and resistances
- which act things belong to

DescentForge's help text also explained how a campaign can change the shop and quest rewards.

Add DescentForge's link and author name here before publishing. I couldn't find a public address
for it, and its terms for reusing the catalog should be checked.
